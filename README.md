# WordsDeluxe
Слова Deluxe - новый способ играть в старые добрые слова.
Этот проект - Web-Приложение для помощи игры в модифицированную версию Слов, где кроме знаний слов и смекалки также играет роль креативность и удача.

## Основная суть
После каждого названного слова - нужно кинуть кость. Выпадает 6-ка - добавляете правило игры. 

(И это правило может быть любым!)

## Подробнее о приложении
Данное приложение создавалось под телефон и работу без интернета. Однако играть можно и на ПК, так же как и онлайн (перейдя на онлайн страничку этого репозитория)

Иконки взяты из Icons8
